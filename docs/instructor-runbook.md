## 📋 ก่อนวันอบรม
- [ ] ส่งลิงก์ [00-setup.md](00-setup.md) ให้ผู้เรียน ≥ 3 วันล่วงหน้า ขอให้ `docker compose pull` + `build` ให้เสร็จ
- [ ] เตรียม API key กลางสำรอง (ตั้ง spend limit) สำหรับผู้ที่ยังไม่มี — แจกผ่านไฟล์ส่วนตัว ไม่ขึ้นจอ
- [ ] ทดสอบเดโม M0 บนเครื่องวิทยากร: Node-RED inject → n8n notify → Telegram → Agent App ครบทั้งเส้น
- [ ] สำรอง Docker images เป็นไฟล์บน USB: `docker save nodered/node-red:5.0 docker.n8n.io/n8nio/n8n:stable node:22-alpine -o images.tar` (ผู้เรียนใช้ `docker load -i images.tar`)
- [ ] เตรียม hotspot มือถือสำรองกรณี Wi‑Fi โรงแรมล่ม
- [ ] ใส่ข้อมูลตัวอย่างใน Data Table และ Agent App ไว้ 5–6 งาน เพื่อให้เดโมดูมีชีวิต

## 🆘 แผนสำรอง

| ปัญหา | ทางแก้ |
|---|---|
| อินเทอร์เน็ตช้า ดึง image ไม่ได้ | `docker load -i images.tar` จาก USB |
| Docker ไม่ขึ้นบนเครื่องผู้เรียน (เครื่ององค์กรล็อก) | จับคู่กับเพื่อน หรือรัน Node-RED/Agent App ด้วย Node.js ตรง (`npx node-red`, `npm start`) |
| API key มีปัญหา / rate limit ทั้งห้อง | ใช้ key สำรอง, ลด effort ใน flow, สลับเป็นเดโมบนจอวิทยากร |
| Telegram ใช้ไม่ได้ | ใช้ No Operation + ดู Executions |
| เวลาไม่พอ | ตัด Lab 4C และ Lab 5 ขั้นที่ 2 เป็นการบ้าน — **อย่าตัด Lab 2 ข้อ 7 และ Lab 5 ขั้นที่ 1** |
| ผู้เรียนเร็วมาก | ส่วนต่อยอดใน 04 (Telegram trigger, Google) และโจทย์ "ท้าทาย" ใน Lab 5 |
